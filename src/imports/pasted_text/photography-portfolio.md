Create a premium one-page photography portfolio website for a photographer based in Ho Chi Minh City.

The website should feel like a digital fashion magazine, not a normal photography portfolio template.

## Overall visual direction

Style keywords:

Editorial photography
Fashion magazine
Art direction
Contemporary
Minimal
Cinematic
Asymmetrical
Bold typography
Large photography
Generous whitespace
Experimental layout
Premium creative portfolio

The website should feel like:

a photography lookbook
an independent fashion magazine
a creative director portfolio
an editorial photo book translated into a website

Avoid the feeling of:

a generic portfolio template
a SaaS landing page
a 3-column image gallery
a WordPress photography theme
rounded cards everywhere
glassmorphism
gradients
large CTA buttons
corporate UI

Photography must be the main visual element.

# Typography

Typography is extremely important.

Use a bold condensed sans-serif style for large headings.

Think of typography used in:

fashion magazines
editorial books
creative studio websites

Combine:

very large condensed display typography

with

small clean sans-serif typography for metadata.

Headings can become extremely large.

Some typography should intentionally:

overlap photographs
extend outside the content grid
touch the edges of the viewport
appear partially cropped

Use typography as part of the composition rather than simply placing text above images.

# VISUAL RHYTHM

The website should constantly change visual rhythm.

Alternate between:

huge photographs

small photographs surrounded by whitespace

large typography

dense photo collages

quiet empty sections

light sections

dark sections

Do not repeat exactly the same layout twice.

Scrolling should feel like turning pages in a photography book.

# INTERACTIONS

Use subtle editorial motion.

When scrolling:

large typography can slowly move

photos can have very subtle parallax

images can gently reveal from below

some text can fade or slide slightly into place

Do not use dramatic animations.

No bouncing.

No exaggerated 3D.

No flashy transitions.

Motion should feel slow, confident and premium.

---

# IMAGE INTERACTION

When hovering a photograph on desktop:

slightly zoom the image

show a small cursor label:

VIEW

or

OPEN

Do not create large buttons over images.

---

# RESPONSIVE DESIGN

Desktop should be experimental and highly art-directed.

Tablet should preserve the editorial feeling while reducing overlaps.

Mobile should NOT simply shrink the desktop layout.

On mobile:

use strong vertical compositions

large typography

full-width photographs

intentional whitespace

simplify complex collages

keep typography visually bold

Do not create horizontal scrolling.

---
